# Security Policy

The Zero-Day Ledger is a static site rebuilt daily from public news feeds and
CISA's KEV catalog, served from Cloudflare at https://thezerodayledger.com.

## Reporting a vulnerability

Please report security issues privately through GitHub:
**[Report a vulnerability](https://github.com/DtAZestie/zero-day-ledger/security/advisories/new)**.
Don't open a public issue for anything exploitable.

In scope: the site and its HTTP headers, the build and deploy pipeline in
this repository, and the domain's DNS and email records.

Out of scope: the content of third-party articles and summaries of them, and
the upstream news sites themselves.

I'll acknowledge a report within a few days. This is a personal project, so
there is no bug bounty, but credit is gladly given.
